# Mehra's Studio Portfolio Website

Welcome to my portfolio website showcasing footwear and leather design work.

## 🎨 Website Features

- **Modern, Bold Design** - Artistic aesthetic that reflects creative work
- **Responsive & Mobile-Friendly** - Works seamlessly on all devices
- **Portfolio Showcase** - Filterable gallery of design projects
- **Blog/Insights** - Share design thoughts and process articles
- **Contact Form** - Easy way for clients to reach out
- **Social Integration** - Links to Instagram, LinkedIn, Behance, and Facebook

## 📁 Pages

- **Home** (`index.html`) - Welcome and featured work
- **Portfolio** (`portfolio.html`) - Complete project gallery with filtering
- **About** (`about.html`) - Personal story and design philosophy
- **Insights** (`blog.html`) - Design articles and process documentation
- **Contact** (`contact.html`) - Get in touch form and social links

## 🚀 Quick Start

1. **Add Your Content**
   - Open each `.html` file and update the content with your information
   - Replace placeholder images with your actual work
   - Update social media links and email

2. **Add Your Images**
   - Create `assets/images/` folder
   - Add your project and portfolio images
   - Update image paths in HTML files

3. **Deploy**
   - Push to GitHub to deploy via GitHub Pages
   - Your site will be live at `https://yourUsername.github.io`
